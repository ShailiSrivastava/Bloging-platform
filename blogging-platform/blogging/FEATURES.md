## 🚀 How to Use

### Creating a Blog
1. Click "Start Writing Now" button
2. Fill in blog details (author, title, category)
3. Write your content using the formatting toolbar
4. Add tags for better discoverability
5. Set estimated read time
6. Click "Publish Blog"

### Discovering Blogs
1. View all published blogs in the feed
2. Use search bar to find specific blogs
3. Filter by category using left sidebar
4. Like blogs you enjoy
5. Share interesting posts

### Managing Blogs
1. Click "Edit" to modify a blog
2. Click "Delete" to remove a blog
3. View your blog statistics on the right sidebar
