## 📚 Each Component Explained

### Backend (`/backend`)
Your Node.js server that handles:
- User registration and login
- Blog CRUD operations
- Comments and replies
- Social features (likes, follows)
- Database queries
- Error handling

**Run with:** `npm start`

### Frontend (`/blogging`)
Your user interface with:
- Responsive design
- Smooth animations
- Dark mode toggle
- Blog editor
- User authentication forms
- Search and filtering

**Open:** Any `.html` file in browser

### Database (MongoDB)
Where data is stored:
- User accounts
- Blog posts
- Comments
- Social relationships

**Start with:** `mongod`

### API Client (`js/api.js`)
The bridge between frontend and backend:
- Makes HTTP requests
- Handles authentication
- Manages responses
- Error handling

**Usage:** Imported in HTML files
